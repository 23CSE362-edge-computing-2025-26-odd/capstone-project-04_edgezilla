## Medical Accuracy Calculation

The system uses **clinically-aware decision evaluation**:

### Sepsis Risk Assessment
- **High Risk (≥0.6)**: Mandatory cloud processing for expert analysis
- **Moderate Risk (0.3-0.6)**: Cloud preferred, edge acceptable if overloaded
- **Low Risk (<0.3)**: Edge processing preferred for efficiency

### Risk Factors
- **Heart Rate**: Tachycardia (>110 bpm), Bradycardia (<50 bpm)
- **SpO2**: Hypoxemia (<92%), Mild Hypoxemia (<95%)
